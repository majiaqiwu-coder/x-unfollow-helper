# X 未回关清理助手

Chrome Manifest V3 浏览器扩展。扫描你在 X 上关注的账号，找出没有回关你的人，然后按保守节奏取关。

> 当前状态：开发预览版。尚未完成不同语言、不同账号规模和 X 页面改版下的浏览器实测，不建议作为稳定版本发布。

本项目与 X Corp. 无关联，也未获得其认可。“X”和相关标识属于其各自权利人。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点“加载已解压的扩展程序”。
4. 选择下载并解压后的项目目录（包含 `manifest.json` 的文件夹）。
5. 安装后如果 X 页面已经开着，先刷新一次 `x.com`。

## 使用

1. 登录 `https://x.com`，保持这个标签页打开。
2. 点 Chrome 工具栏里的“X 未回关清理助手”。
3. 用户名一般会自动识别；识别不到时手动填写。
4. “先预览名单”会扫描并保存候选账号，之后由你单独启动取关。
5. “边扫边清理”会在读取关注列表时复核回关标记，并立即按所选速度处理。
6. “限量模式”默认过去一小时最多尝试 15 次；“不限制模式”会连续执行并要求确认风险。
8. 开启“允许后台运行”后可以切换到其他标签页；执行任务的 X 标签页仍需保留。

## 参数

- 每小时取关数量：限量模式下过去 60 分钟最多尝试的次数。
- 24 小时最多尝试：限量模式下滚动 24 小时窗口内的尝试上限。
- 最低滚动次数：扫描会根据关注人数自动提高次数，上限 3000 次。
- 基础间隔：两次取关之间的固定秒数。
- 随机增加：在基础间隔上额外增加的随机秒数。

“使用推荐默认值”会设置为过去一小时最多尝试 10 次、过去 24 小时最多尝试 40 次、操作间隔 30–45 秒。这些是本地设置，不是平台安全额度。

## 0.7.0 推荐默认值

- 增加“使用推荐默认值”按钮。
- 默认每小时 10 次、滚动 24 小时 40 次、间隔 30–45 秒。
- 小时和 24 小时额度都按操作尝试记录；状态不明的尝试也会占用额度。

## 0.8.0 名单预览

- 待处理名单支持用户名搜索和每页 20 个账号的分页查看。
- 点击用户名可以打开对应 X 主页。
- 点击“保留”会将账号移入永久保留名单；以后更新扫描和边扫任务都会跳过。
- 在“已保留”标签中可以将账号移回待处理名单。

## 0.9.0 日常使用

- 增加暂停和继续。暂停保留任务、扫描统计、已检查账号及限额状态；“结束任务”会清除当前任务。
- 主界面保留工作方式和执行速度，高级参数默认折叠。
- 增加最近任务记录和不包含账号名单的诊断 JSON 导出。
- 增加新关注观察期，推荐默认 3 天。插件会记录本浏览器中之后发生的关注点击，在观察期内跳过该账号。

观察期无法获知安装扩展之前、手机端或其他浏览器发生的关注时间，这些账号不会自动获得观察期保护。

## 0.2.0 更新

- 在 `chrome://extensions` 重新加载扩展，再刷新 X 页面。
- 旧名单作废，请打开自己的个人主页重新扫描。用户名必须与登录账号一致。
- 先读取准确人数再核对名单；人数缩写或扫描不完整会停止。
- 点击前检查停止请求；只有观察到明确的未关注按钮才计入成功，状态不明确会停止。
- 小时额度记录尝试次数，刷新不会重置。同一域名的标签页不能同时执行取关。
- 未处理项目显示剩余数量，不再把部分完成显示为全部成功。
- 仍需保持原标签页打开；休眠、后台节流会推迟下一轮。

尚未在真实 X 账号上验证。人数核对不是完整性的绝对保证，X 页面结构变更可能导致拒绝扫描或停止执行。

## 0.3.0 后台运行

- X 标签页可以放到后台，弹窗关闭后任务继续。
- 限量模式的下一轮使用 Chrome 后台定时器唤醒，不再依赖页面计时器。
- 必须保留执行任务的 X 标签页，并保持 Chrome 运行。关闭标签页或 Chrome 后不会继续操作。
- 电脑休眠时不会操作；唤醒后 Chrome 会补触发到期任务。
- 扫描数千个账号仍依赖 X 页面逐页加载。标签页在后台时 Chrome 可能限制页面速度，因此扫描会更慢。

0.3.1 增加“允许后台运行”开关。开启时使用 Chrome 后台定时器；关闭时启动任务会切到 X 标签页，下一轮使用页面计时器，需要保持 X 页面活跃。开关只影响新任务。

0.3.2 将完整扫描结果长期保存在本机。关闭弹窗、刷新页面或下次打开浏览器后，可以直接用保存的剩余名单继续取关，不再要求每 30 分钟重新扫描。新扫描失败时保留旧名单；点击“更新名单”才会重新扫描，成功后替换旧名单。名单可能随关注关系变化而过时。

## 0.4.0 任务恢复

任务和名单都写入 `chrome.storage.local`。页面导航、标签页刷新或浏览器重启后，重新打开原账号的 X 页面可以恢复等待中的任务。扫描只会在完成“正在关注”阶段后保存该阶段名单；阶段中途关闭页面仍需重扫该阶段。

0.4.1 为任务绑定原 X 标签页，避免多个标签页同时恢复并重复执行。

## 0.5.0 分段扫描

扫描不再要求 X 一次加载完整关注与粉丝列表。插件读取“正在关注”列表中每个账号的“关注了你”标记，本轮加载停止时会保存已经确认的候选账号，并与以前保存的名单合并。取关前会在当前列表再次检查“关注了你”标记，已回关账号会跳过。界面会区分完整扫描与分段扫描。

分段扫描适合关注数量较大的账号，但只能覆盖本轮实际加载的用户。重复扫描不保证发现顺序固定，也不能代替 X 官方 API 提供的完整关系数据。

## 0.6.0 工作方式

- 先预览名单：保存扫描结果，用户检查后再开始取关。
- 边扫边清理：每加载一个关注账号就检查“关注了你”标记，未回关账号立即进入取关流程。
- 两种工作方式都可以选择限量或不限制速度，也支持后台运行开关。
- 边扫任务保存已检查与已处理账号；页面导航和限量等待后可以继续。

## 隐私

扩展读取 X 页面中已经展示的用户名、关注关系和按钮状态，只用于本地比较与执行用户发起的操作。详情见 [PRIVACY.md](PRIVACY.md)。

## 安全说明

- 所有数据只保存在本机 Chrome 的 `chrome.storage.local`，不上传服务器。
- 扩展不会自动关注，也不会批量关注。
- 详细限流建议见 [RULES.md](RULES.md)。

## 文件

- `manifest.json`：扩展配置。
- `content.js`：X 页面里的扫描与取关逻辑。
- `popup.html`、`popup.css`、`popup.js`：控制面板。
